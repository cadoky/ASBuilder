Thanks for the feedback on Discord, this one is mostly your ideas.

- **Recommended stats**: the planner window is a bit wider and has a new column where you can write the stats a build should reach: Damage, Cooldowns, Crit Chance, Crit Damage, Area, Speed, Armor / DR, Lifesteal, Pickup, Luck and Gold. Each stage (Early, Mid, End, Endless) has its own values, like the notes. Leave a box empty to skip it. The stats go into the export code too.
- **Two targets for two-stat amulets**: amulets with a second stat (South Seas Kelp: luck + gold, for example) now get a second target box. The tracker counts the amulet as done only when both values are reached.
- **Longer notes**: the notes limit went from 2000 to 4000 characters.
- **Fixed**: the Save button now lights up while you type in the name, notes or stage name box. Before, you had to click something else first.

Codes with the new stats still import in 1.3.0; the stats are just skipped there.
