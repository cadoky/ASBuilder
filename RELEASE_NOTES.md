## ASBuilder 1.2.0

- Jewelry in the tracker now gets the same dot as spells: green if the piece you're wearing is in your build, violet if it isn't.
- Once both ring and both trinket slots are filled, the missing ring/trinket suggestions drop off the jewelry list, so only amulet suggestions stay.
- You can now pick up to 3 alternative amulets (was 2), so 4 amulets in total.
