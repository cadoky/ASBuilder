More quality-of-life stuff, again mostly from your feedback.

- **Current stats next to the recommended ones**: the stats column now has a "Now" value for every row, taken from your character window. Green means you reached the recommended value, orange means you're below it. The game only sends these numbers now and then, so if you see "-", open your character window (C) once during a run.
- **Font choice**: there's a "Font" button at the top of the planner. Besides the game's own font you can pick Inter, Lato, Nunito, Lexend or Noto Sans. It changes the planner and the tracker. New font files need a full game restart, a /reload is not enough.
- **Notes and image link are locked**: you can't change them by accident anymore. Click, select and copy (Ctrl+C) still work. Press the small "Edit" button at the top right of the box to change the text, then the tick to keep it or the cross to undo. You still press Save to save the build.
- **Resize the tracker**: drag the small grip at the tracker's bottom right corner to make it bigger or smaller. Same as `/asb scale`, and `/asb reset` puts it back.

If a font doesn't show up after updating, close the game completely and start it again.
