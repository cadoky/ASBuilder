Updated for the Shaman rework (game 0.134.0).

- New Shaman data: 12 spells, the new legendary amulets (Eye of the Tempest, Cinderheart, Winter's Embrace, Earthshatter, Emberwake) and Medallion of the Bladestorm for Rockbiter Weapon. Healing Wave and Lightning Shield have no amulet anymore.
- Rockbiter Weapon is in the spell list. If a build's talents include Rockbiter Initiation, it gets added to the build on import.
- Amulet picks from old builds that no longer exist in the game are skipped on import instead of showing up as "?".
- Updated legendary amulet effect texts to match the in-game details panel.
